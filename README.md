## Descrição

Um mini projeto para disciplina de Banco de Dados II, cujo tema é um *Sistema de Agendamento de Consultas*.

## Instalação

Instale o Python, Postgresql, DBeaver ou PGadmin.
Instale o psycopg2 usando o pip:
```bash pip install psycopg2-binary```

## Configuração

Crie uma base de dados e popule-a usando o *script_etapa_2.sql*.
Ajuste os parametros de conexão no arquivo *cli.py*.

## Executando

No Linux:
```bash python3 cli.py```
No Windows:
```bash python clip.py```
